# Slingshot Dummy

**Game #2** in the **[JakePlay.com](https://jakeplay.com)** pixel arcade lineup by **[JakeTeam LLC](https://jaketeam.com)** — starring Matchstick's bouncy crash-test dummy cousin!

- **Genre:** One-Finger Pull-Back Pixel Pinball & Boss-Slam Arena (Web + iOS/Android Capacitor ready)
- **Subdomain Target:** `https://sling.jakeplay.com`

## Features
- **One-Finger Pull-Back Slingshot Physics:** Drag anywhere on screen to aim with real-time dotted trajectory preview, release to ricochet across pinball rooms, smash crates, chain-detonate TNT barrels, and rack up `COMBO ×N` bonuses!
- **20 Handcrafted Arenas + 4 Mini-Bosses:** 5 visual themes (*Crash-Test Lab*, *Neon Pinball Arcade*, *Ice Rink Ricochet*, *Lava Foundry*, *Matchbox Royal Throne*) culminating in *King Matchbox Mech* (rotating shield!).
- **4 Difficulty Modes:** `🐥 EASY` (2-bounce aim assist + troll roasts), `⚡ NORMAL`, `🔥 HARD`, and `💀 ULTIMATE` (zero aim preview, max speed!).
- **JakePlay Shared Accounts, Stats & Locks:** Linear progression (beat Arena `N` to unlock `N+1`; Premium unlocks all 20), per-arena tries-to-complete & bonk tracking, COPPA 13+ registration, in-app Delete Account, and strict CSP security headers.
